R4OS SDK Host-Profil Linux
==========================

Dieses Profil ist die spaetere externe Linux-Buildhuelle fuer denselben
SDK-Kern.

Linux soll keine eigene ABI-Schicht bekommen. Unterschiede duerfen nur
Toolpfade, Scriptnamen, Runner und Paketierung betreffen. R4XStart, R4L,
R4M0, Linkprofil, Header und Zig-Bindings bleiben identisch zum Windows-Host.
